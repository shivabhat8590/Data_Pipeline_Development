# Titanic Data Pipeline Project

This project demonstrates an ETL (Extract, Transform, Load) pipeline using Python, Pandas, and Scikit-learn for preprocessing Titanic dataset data.
Data Pipeline Development using Python
>Overview Project Flow
CSV Dataset
   ↓
Read using Pandas
   ↓
Handle Missing Values
   ↓
Remove Duplicate Records
   ↓
Encode Categorical Data
   ↓
Feature Scaling
   ↓
Save Cleaned Data

>Features
Data extraction from CSV files
Missing value handling
Duplicate row removal
Categorical data encoding
Feature scaling using StandardScaler
Automated data preprocessing pipeline
Cleaned dataset export
Simple and modular project structure

>Technologies Used
Python
Pandas
NumPy
Scikit-learn
